## 五、拍屏避坑（重要）

屏幕是 **57.5Hz** 刷新，直接用 30fps 手持拍会出现**扫描条纹 / 明暗滚动**。

**相机/手机设置**

| 项目 | 建议 |
|---|---|
| 快门 | 手动固定 **1/50s** 或 **1/60s**（不要自动） |
| 帧率 | 拍 **60fps**，后期放 30fps 时间线，画面更稳 |
| ISO | 尽量低，靠打光提亮 |
| 白平衡 | 手动锁定，别让屏幕颜色随环境漂 |
| 对焦 | 手动对焦到屏幕，锁定 |
| 曝光 | 手动，降低曝光补偿让屏幕不过曝 |

**如果还是有条纹**

1. 换 1/50 或 1/100 快门试（和设备刷新率做整数关系）
2. 降低屏幕亮度（PWM 占比变化，条纹会减轻）
3. 后期用「去闪烁」插件（Premiere: 去除闪烁 / DaVinci: Deflicker）

**灯光**

- 主光从侧后方打，勾出外壳轮廓
- 屏幕正面不要直射光（会反光出白斑）
- 背景压暗，让屏幕自己发光

## 六、剪辑与节奏

- **BGM**：前 15 秒用节奏强的（抓人），功能演示段换成轻电子/lo-fi，彩蛋段留白
- **字幕**：全片加，重点数字放大加粗（57.5Hz / 480×480 / 6 个插件）
- **转场**：功能段用硬切，段与段之间用「屏幕亮起」或「手入画」过渡
- **色调**：偏冷，突出屏幕的荧光感
- **卡点**：六屏快闪那段对齐鼓点

## 七、可选的竖屏 60 秒版

如果要在抖音/视频号分发，剪一版 60 秒：

2. 5–20s：六屏快闪
3. 20–40s：音乐封面旋转 + CPU 环变红

5. 50–60s：仓库地址 + 「开源」

## 八、拍摄顺序建议（省时间）

1. 先拍**静态外观**（转台、细节、场景）——这时候设备不用跑任何插件
2. 再拍**功能演示**（需要电脑配合、要跑脚本）
3. 最后拍**录屏**（网页后台、编辑器）——这个可以事后补
4. 彩蛋镜头留到最后拍（要关灯、清场）
