# 三角洲行动插件

摆件上显示：**昵称、烽火段位分、流动总资产、非流动总资产、最近收益**（红涨绿跌带箭头）。

## 为什么数据要在电脑上拉

整条链路的瓶颈不是算力，是**登录**：

- 授权码 `code` 只有**分钟级**有效期，且一次性；
- 必须由浏览器完成 QQ 登录才能拿到 code；
- 拿到 code 后要在几十秒内换成 `openid + access_token`（有效期 60 天）。

在设备上做这件事意味着：屏幕只显示一个倒计时，用户要在几十秒内完成「复制链接 → 粘贴 → 保存」，
而且设备网络抖一下（TLS 握手 20KB 内存、DNS 失败）整个码就废了。

所以采用**推模式**：

```
┌─ 电脑 ────────────────────────────┐        ┌─ 摆件 ──────────┐
│ tools/df_sync.py                  │        │ 三角洲插件       │
│  ① 换令牌（一次）                 │  HTTP  │                  │
│  ② 每 5 分钟拉腾讯 AMS 接口       │ ─────> │ POST /api/dfm    │
│  ③ 把结果 POST 给摆件             │        │ 写 data.json     │
└───────────────────────────────────┘        │ 只负责画         │
                                             └──────────────────┘
```

摆件不做任何网络请求，也不存令牌——令牌只在电脑上（`tools/df_token.json`）。

## 用法

```bash
# 1. 登录（一次，60 天有效）
python tools/df_sync.py login
#   按提示在浏览器里登录 QQ，然后把 qccallback 那条链接粘回来

# 2. 推送
python tools/df_sync.py run --host 10.165.41.102
#   设备 IP 看摆件「网络」屏上显示的那一行

# 只推一次 / 改间隔
python tools/df_sync.py run --host 10.165.41.102 --once
python tools/df_sync.py run --host 10.165.41.102 --interval 600
```

推成功后电脑上会打印：

```
  黒人杀手大张伟  段位 5087  流动 1.74亿  非流动 5558万  收益 -934.1万  -> {"ok":true}
```

摆件上「三角洲」屏每 2 秒重新读一次数据文件，脚本推完 2 秒内就会刷新。

## 接口

摆件端只有一个接口，你也可以手动推：

```bash
curl -X POST "http://10.165.41.102/api/dfm?nick=%E6%B5%8B%E8%AF%95&rank=5087&liquid=174192696&noncur=55579713&gain=-9341475&ts=$(date +%s)"
```

| 参数 | 说明 |
|---|---|
| `nick` | 昵称，UTF-8 URL 编码 |
| `rank` | 烽火段位分 |
| `liquid` | 流动总资产（游戏币） |
| `noncur` | 非流动总资产 |
| `gain` | 最近收益，正数红↑ 负数绿↓ |
| `ts` | unix 秒；超过 30 分钟屏幕会提示「数据 N 分钟前」 |

## 数据字段来源

| 显示 | 接口 | 字段 |
|---|---|---|
| 昵称 | 图表 317814 `userData` | `charac_name`（URL 编码的 UTF-8） |
| 段位分 | 同上 `careerData` | `rankpoint` |
| 流动 | 同上 | `totalprice - noncurrentasset` |
| 非流动 | 同上 | `noncurrentasset` |
| 最近收益 | 图表 316969 `solDetail` | `recentGain` |

## 注意

- **令牌等同账号权限**：`df_token.json` 能读你账号的全部游戏数据，别提交到仓库、别发群。
  本项目 `.gitignore` 已排除它。
- 接口是腾讯内部业务接口，没有稳定性承诺，字段变了脚本要跟着改。
- 只能查**本人**账号（openid 按应用签发，不存在按 UID 查别人的合法通道）。
- 建议推送间隔 ≥ 5 分钟，避免触发风控。
