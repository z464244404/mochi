## 1. 第一次开机

1. 插上 TF 卡（**必须插**：所有素材和插件都在卡上），USB 供电。
2. 屏幕先黑一下（面板初始化），然后进入**网络屏**：
   ```
       WIFI NOT CONNECTED
          JOIN HOTSPOT
           Mochi-XXXX        ← 后四位是 MAC
         PASS mochi1234
            THEN OPEN
        http://192.168.4.1
   ```
3. 手机连这个热点（密码 `mochi1234`），浏览器打开 **http://192.168.4.1**。
4. 网页上「WiFi」→ 扫描 → 选你家 2.4G 的 SSID → 输密码 → 连接。
5. 连上后屏幕会显示路由器分配的 IP（比如 `192.168.4.102`），几秒后自动进桌宠。
   之后**手机切回家里 WiFi**，用那个 IP 也能打开后台。

> 只支持 **2.4G**。5G 的 SSID 扫到了也连不上。

## 2. 四块屏幕

摇一摇按顺序轮换：**网络 → 桌宠 → 时钟 → 天气 →（你装的其他插件）**。

### 网络屏
- 没联网：热点信息 + `http://192.168.4.1`
- 已联网：`CONNECTED` + 本机 IP + `http://<ip>`
- 连接失败时底部显示 `ERR <原因码>`（15/204/205 = 密码错，201 = 没找到）

### 桌宠
- 三段动画按 DeepSeek 余额状态切换：**余额在掉 → 打字**、**5 分钟没变 → 吃饭**、**30 分钟没变 → 睡觉**
- 底部叠加：左边「余额」、右边「今日」、正中「峰/谷」
- 没填 API key 时显示 `SET API KEY`

### 时钟
三种样式在「插件 → 时钟 → 详情」里切换：

| 样式 | 样子 |
|---|---|
| `cute` | 奶油色背景、小太阳、大号时间、日期药丸（含周几）、秒进度环 |
| `tech` | 深色、60 格刻度、秒弧 + 游标、`2026.11.12 THU` |
| `minimal` | 只有时针/分针/秒针 + 12 个刻度，背景/指针/秒针颜色都可调 |

### 天气
- 顶部地名（插件设置里的「地名」）
- 大号温度 + ℃、天气词（晴/多云/阴/小雨/中雨/大雨/暴雨/雷阵雨/雪/雾）
- 大图标是 meteocons 的**原始动画**，背景随天气变化
- 下面三天：日期 / 图标 / 高温（橙）/ 低温（蓝）
- 10 分钟刷新一次；没网时显示「等待网络」，有缓存时直接显示缓存不报错

## 4. 网页后台

地址：连热点用 `http://192.168.4.1`，连家里 WiFi 用设备显示的 IP。

### 状态卡
固件版本、当前应用、帧率、PSRAM 余量、热点名、**热点地址**和**局域网地址**、WiFi 状态。

### 插件
- 列表里每行是一个插件：`内置`/卡上插件，右边的勾是**启用开关**（停用后不进轮换）
- 点名字进**详情页**：显示 manifest 信息，并按 `settings` 自动生成表单
  - 支持文本、数字、下拉、颜色选择器
  - 改完点「保存设置」→ 立刻写卡并让插件重新加载，不用重启
- 「删除」只对卡上的 Lua 插件有效，内置的删不掉

### 示例插件
固件里带了两个示例，点「安装」会写到卡上：

- **时钟**（cute / tech / minimal）
- **天气**（实时 + 三天，Open-Meteo，不用注册）

内置插件按版本号自动更新：固件升级后，卡上的示例插件会在开机时自动重装成新版本。
你自己改过它们的代码就会被覆盖，介意的话先备份。

### WiFi
- **扫描附近 WiFi**：列出 SSID + 信号强度，点一下填入输入框
- 连接状态实时刷新，失败会给中文原因
- 热点一直保留，连上家里 WiFi 也不影响

### 固件（OTA）
上传 `mochi.bin` 即可升级，不用插串口。升级后设备自动重启。

## 5. DeepSeek 余额

桌宠底部那条数据来自 DeepSeek 官方接口，需要你自己的 API key。

**填法**：网页 →「桌宠」→ 详情 → `DeepSeek API Key` → 保存。

| 显示 | 含义 |
|---|---|
| `余额 12.34` | 账户总余额（人民币） |
| `今日 0.56` | 今天累计花掉的（每次余额下降的累加） |
| `谷` / `峰` | 当前是否在优惠时段：**工作日 09:00–12:00、14:00–18:00（北京时间）是峰时**，其余（含周末）都是谷时 |

说明：

- 余额 5 分钟查一次，查不到不影响显示（沿用上次的数）
- key 明文存在 `/sdcard/plugins/pet/settings.json`，**不编进固件**
- 官方没有「今日用量」接口，这里是按余额下降累加估算的；关机期间「又花钱又充值」的差额算不出来
- 法定节假日没有内置日历，节假日当天仍按工作日算峰谷

## 6. 常见问题

**屏幕显示 `NO PLUGIN` / `PLUGIN MISSING`**
插件目录里的 `main.lua` 不见了。进这个屏幕时固件会自动从内置副本重装一次；
还不行就在网页上删掉重新安装。

**天气一直是「等待网络」**
看网络屏有没有 IP。有 IP 还不行，多半是路由器把 DNS 拦了；串口日志里会有 `getaddrinfo` 报错。

**屏幕显示 `NO ASSET`**
TF 卡里没有 `pet.mjp`。重新走一次完整烧录（`idf.py flash`），设备会自动把素材同步到卡上。

**改完设置没变化**
详情页保存后插件会重载，但要等它重新画一帧。若还是旧的，切到别的屏幕再切回来。

**卡拔了会怎样**
素材和插件都没了，屏幕显示 `NO ASSET`，网页也读不到插件列表。插回去重启即可。

**怎么恢复出厂**
网页删掉所有插件，重新烧一次固件即可；NVS 里的 WiFi/设置会被保留，
要清空可以 `idf.py -p COM10 erase-flash`（会连固件一起擦掉）。
