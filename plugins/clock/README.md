# 时钟 · Mochi 插件

给 [Mochi](https://github.com/z464244404/mochi) 桌面摆件的时钟屏，三种样式：

| 样式 | 样子 |
|---|---|
| `cute` | 奶油色背景、小太阳、大号时间、日期药丸（含周几）、秒进度环 |
| `tech` | 深色背景、60 格刻度、秒弧 + 游标、`2026.11.12 THU` |
| `minimal` | 只有时针/分针/秒针 + 12 个刻度，背景/指针/秒针颜色都可调 |

## 安装

设备网页后台 →「安装 / 更新插件」→ 同时选中本目录的 `manifest.json` 和 `main.lua` → 上传。

或者直接拷到卡上：`/sdcard/plugins/clock/`（两个文件），重启设备。

## 设置

插件详情页里可以改：

| 项 | 说明 |
|---|---|
| 样式 | `cute` / `tech` / `minimal` |
| 显示秒针 | 开 / 关 |
| 背景色、指针色、秒针色 | 仅 `minimal` 有效，颜色选择器 |

## 说明

- 纯本地绘制，不联网
- 时间来自设备 RTC / NTP
- 字号只有四档（106 / 56 / 29 / 22），本插件只用到 106（数字）和 29（文字）
