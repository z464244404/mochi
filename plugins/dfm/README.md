# 三角洲行动 · Mochi 插件

给 [Mochi](https://github.com/z464244404/mochi) 桌面摆件的《三角洲行动》数据屏：

**昵称、烽火段位分、流动总资产、非流动总资产、最近收益**（红涨绿跌带箭头）。

## 为什么数据要在电脑上拉

整条链路的瓶颈不是算力，是**登录**：

- 授权码 `code` 只有**分钟级**有效期，且一次性
- 必须由浏览器完成 QQ 登录才能拿到 code
- 拿到后要在几十秒内换成 `openid + access_token`（有效期 60 天）

在设备上做这件事意味着屏幕只显示倒计时，用户要在几十秒内完成「复制 → 粘贴 → 保存」，
而且网络抖一下整个码就废了。所以采用**推模式**：

```
┌─ 电脑 ────────────────────────────┐        ┌─ 摆件 ──────────┐
│ tools/df_sync.py                  │        │ 三角洲插件       │
│  ① 换令牌（一次）                 │  HTTP  │                  │
│  ② 每 5 分钟拉腾讯 AMS 接口       │ ─────> │ POST /api/dfm    │
│  ③ 把结果 POST 给摆件             │        │ 写 data.json     │
└───────────────────────────────────┘        │ 只负责画         │
                                             └──────────────────┘
```

摆件不做任何网络请求，也不存令牌——令牌只在电脑上（`tools/df_token.json`）。

## 用法

```bash
# 1. 登录（一次，60 天有效）
python tools/df_sync.py login
#   按提示在浏览器里登录 QQ，然后把 qccallback 那条链接粘回来

# 2. 推送
python tools/df_sync.py run --host <摆件IP>
```

推成功后电脑上会打印：

```
  黒人杀手大张伟  段位 5087  流动 1.74亿  非流动 5558万  收益 -934.1万  -> {"ok":true}
```

## 安装

网页后台「安装 / 更新插件」→ 选中 `manifest.json` + `main.lua` → 上传。

推送脚本在 [主仓库的 tools/df_sync.py](https://github.com/z464244404/mochi/blob/main/tools/df_sync.py)。

## 接口

摆件端只有一个接口，也可以手动推：

```bash
curl -X POST "http://<IP>/api/dfm?nick=%E6%B5%8B%E8%AF%95&rank=5087&liquid=174192696&noncur=55579713&gain=-9341475&ts=$(date +%s)"
```

| 参数 | 说明 |
|---|---|
| `nick` | 昵称，UTF-8 URL 编码 |
| `rank` | 烽火段位分 |
| `liquid` | 流动总资产（游戏币） |
| `noncur` | 非流动总资产 |
| `gain` | 最近收益，正数红↑ 负数绿↓ |
| `ts` | unix 秒；超过 30 分钟屏幕提示「数据 N 分钟前」 |

## 注意

- **令牌等同账号权限**：`df_token.json` 能读该账号全部游戏数据，别提交、别外传
- 接口是腾讯内部业务接口，无稳定性承诺，字段变了脚本要跟着改
- 只能查**本人**账号
- 建议推送间隔 ≥ 5 分钟
